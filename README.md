# learning-jev

Jev-like 의사결정 모델 학습 노트와 실습.

- `notebooks/`: 실습 노트북 (`jev.ipynb`, `jevlike_training.ipynb`)
- `docs/`: GitHub Pages로 공개하는 자료. `docs/index.html`이 목록 페이지다.
  - 사이트: https://simonjisu.github.io/learning-jev/
  - 새 자료는 `docs/` 아래(발표 자료는 `docs/slides/`)에 두고 `docs/index.html` 목록에 한 줄 추가한다.
  - `docs/` 밖으로 가는 링크는 상대 경로 대신 `https://github.com/simonjisu/learning-jev/blob/main/...` 절대 URL로 건다.
